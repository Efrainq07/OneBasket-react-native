## About the Project

OneBasket is a mobile application that allows users to invest in crypto ETFs. The project is built with React Native and uses Supabase for the backend.

## Getting Started

To get a local copy up and running follow these simple example steps.

### Prerequisites

- Node.js
- npm
- Expo CLI

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Efrainq07/OneBasket-react-native.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Run the app
   ```sh
   npx expo start
   ```
